# Histórico de governança da conta Finish-Him

Conteúdo absorvido do antigo repositório `.github` durante a consolidação da conta.

## Estrutura canônica

A conta mantém três repositórios:

1. `Finish-Him` — perfil público e este histórico de governança;
2. `finish-him-monorepo` — projetos, ferramentas, estudos e dados privados;
3. `workspace-meta` — documentação do workspace local.

Os repositórios anteriores tiveram seu histórico incorporado ao monorepo. Branches legadas relevantes foram preservadas como tags `legacy/...` antes da remoção dos repositórios de origem.

Produtos empresariais continuam pertencendo à [Msc-Company-Org](https://github.com/Msc-Company-Org), e projetos institucionais do Detran-RJ permanecem em [Detran-RJ](https://github.com/Detran-RJ).
